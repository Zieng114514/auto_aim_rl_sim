# 2026-10-13 13:00 击杀质量定义 + 42mm 接口预留 + 差距清单补全

## 做了什么

1. 确立"击杀质量"口径（agnet_experience.md §4.5）：**热量不超限（不锁枪、不扣血）
   的前提下更短的 TTK**；评价三件套 = 热量约束下的 TTK / 击杀频率 / 窗口内命中率。
   依据：裁判系统超热量不只锁枪还**扣血**（负责人提示），所以"不超热量"是生存问题。
2. 阶段 0 增补两项（agnet.md §3）：枪口热量模型（每发升温/冷却/超限锁枪+扣血）、
   弹丸随机散布（枪口精度 σ + 初速波动，真机同样存在）。
3. 预留 42mm 口径接口：弹丸直径/质量/初速模型/单发伤害/射速与热量消耗全部参数化，
   17mm 与 42mm 各一套；sp_vision 侧 aimer 弹道按口径切换；检测/跟踪不动。
4. 弹速模型每发升温增量按默认值（指数逼近、τ≈20 发），负责人认可。
5. 差距清单从 10 条扩到 21 条，并新增 §2.1 头脑风暴（10 条比赛会遇到但 sim 没建模
   的问题，首条 = **我方机器人在动**——云台挂在静止基座上 vs 真机在移动底盘上）。

## 决策

* RL 阶段 1 的验收：热量模型上线后按"热量约束下的 TTK"；上线前用固定阈值 Pareto 曲线
  过渡。**任何调参/训练结论必须同时报命中率 + TTK + 每击杀弹量 + 击杀频率。**
